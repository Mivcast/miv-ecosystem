# Categoria — Estratégias de Marketing (exceto Calendário)

Os cards desta categoria seguem uma lógica compartilhada de experiência, sem
obrigar o conteúdo interno de cada card a ser igual.

Cards:
- Canais;
- Marketing físico/local;
- Marketing para equipes;
- Marketing para clientes;
- Parcerias/influenciadores;
- Identidade visual aplicada ao marketing;
- Brindes & bonificações.

## Padrão de experiência
1. Introdução curta sobre a importância do tema.
2. Aviso do Perfil Mestre da Empresa e percentual preenchido.
3. Checklist prático.
4. Três estados persistentes:
   - Está certo;
   - Preciso fazer isso;
   - Não se aplica.
5. Cor visual do item conforme estado.
6. Em cada ponto:
   - Sugestão para este ponto (premium);
   - Perguntar ao MARK.IA (premium).
7. Progresso salvo.
8. Relatório persistente, imprimível/compartilhável.
9. Sugestões futuras devem cruzar metodologia + Perfil Mestre + contexto do card.

O Calendário Inteligente é exceção e continua com sua própria experiência.
