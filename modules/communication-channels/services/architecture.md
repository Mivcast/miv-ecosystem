# Serviços previstos

- `channelRegistry`: catálogo de canais.
- `channelRelevance`: relevância conforme empresa/nicho/momento.
- `checklistPersistence`: salvar estado de cada item.
- `channelScoring`: calcular percentual por canal.
- `overallScoring`: visão geral.
- `priorityEngine`: impacto x esforço x relevância.
- `recommendationGenerator`: orientação contextual.
- `channelReport`: relatório imprimível/compartilhável.
- `externalPracticeUpdater`: consultar informação atualizada quando necessário.
