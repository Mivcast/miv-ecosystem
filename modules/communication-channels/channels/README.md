# Catálogo de canais

Cada canal poderá ter seu próprio arquivo.

O arquivo deve conter:
- id;
- nome;
- grupo;
- introdução curta;
- funções do canal;
- quando é relevante;
- sinais de baixa relevância;
- checklist base;
- peso/prioridade dos itens;
- regras específicas;
- exemplos;
- campos que podem ser personalizados pela IA.

Começamos pelo Instagram como referência de conteúdo, sem obrigar outros canais
a terem a mesma quantidade de itens.
