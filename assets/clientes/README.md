# Client Logos

Logos usados no carrossel de clientes/prova social do index.

- Formato preferencial: `.webp`.
- O app carrega os arquivos listados em `renderLogos()` no `app.js`.
- Mantenha arquivos leves, com fundo transparente sempre que possivel.
- Para adicionar novas logos, coloque o arquivo nesta pasta e inclua o nome no array `logos`.
