# Fotos dos Depoimentos

Coloque aqui as fotos pequenas usadas nos depoimentos simulados ou, no futuro, nos depoimentos reais autorizados.

Formato esperado: imagem quadrada em WebP ou JPG, idealmente 160x160 px. O app procura estes nomes:

- `depoimento-01.webp`
- `depoimento-02.webp`
- ...
- `depoimento-50.webp`

Se uma foto nao existir, o depoimento mostra as iniciais do nome como fallback.

Importante: use fotos reais apenas com autorizacao da pessoa. Para relatos ficticios, prefira fotos geradas ou bancos com licenca adequada.
